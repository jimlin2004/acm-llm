# A2 — RC cutoff hand calculation (4.7k / 33n -> 1026 Hz)

**Group:** theory  
**Status:** completed  •  **Time:** 9.0s  •  **Auto:** PASS

## Prompt

An RC low-pass filter has R = 4.7 kohm and C = 33 nF. Calculate the -3 dB cutoff frequency. Show the result in Hz.

## Checks

- ✅ `number_near` — 1026.0±3.0% (found [1026.14, 1026.0, 1030.0])

## Expected (manual bar)

fc = 1/(2*pi*R*C) = 1026 Hz.

## Reply



The -3 dB cutoff frequency \(f_c\) for an RC low-pass filter is given by:

\[
f_c = \frac{1}{2\pi RC}
\]

**Given:**
- \(R = 4.7 \, \text{k}\Omega = 4700 \, \Omega\)
- \(C = 33 \, \text{nF} = 33 \times 10^{-9} \, \text{F}\)

**Calculation:**
\[
f_c = \frac{1}{2\pi \times 4700 \times 33 \times 10^{-9}} \approx \frac{1}{9.7452 \times 10^{-4}} \approx 1026.14 \, \text{Hz}
\]

**Result:**  
The -3 dB cutoff frequency is approximately **1026 Hz** (or ~1.03 kHz).
