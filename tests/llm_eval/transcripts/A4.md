# A4 — MOSFET operating region (VGS-VTH > VDS -> triode)

**Group:** theory  
**Status:** completed  •  **Time:** 6.6s  •  **Auto:** PASS

## Prompt

An NMOS transistor has VTH = 0.7 V, VGS = 1.5 V and VDS = 0.5 V. Which operating region is it in? Explain briefly.

## Checks

- ✅ `contains_any` — any of ['triode|linear|ohmic']

## Expected (manual bar)

VOV = 0.8 V > VDS = 0.5 V -> triode/linear region.

## Reply



The NMOS transistor is operating in the **triode (linear) region**.

**Brief explanation:**
1. Since `V_GS` (1.5 V) > `V_TH` (0.7 V), the transistor is turned on.
2. The overdrive voltage is `V_GS − V_TH = 0.8 V`.
3. Because `V_DS` (0.5 V) is **less than** this overdrive voltage, the inversion channel is not pinched off at the drain end. This `V_DS < V_GS − V_TH` condition defines the triode region.
